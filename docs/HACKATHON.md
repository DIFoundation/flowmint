## Track strategy
Optimize first for genuine real-world adoption. Other prizes should emerge naturally from the same product, not from artificial features or farming.

### Real World Adoption — $1,000
Measured by verified users, returning users (active on 2+ distinct days), and distinct signers/authorisers. Sponsored-relay signers and EIP-3009 authorisers count, not only gas payers.

### Value Moved — $1,500 / $500
Adjusted volume between independent parties. Exclusions include self-transfers, mint/burn, protocol trades, transfers to/from own contracts and TVL rebalance. Distinct signers gate volume.

### Best Stablecoin Adoption — $750
Description supplied by Celo Builders favors cNGN, Ripio wFIAT, USAT and x402 settlement. The supplied rules say facilitator settlement currently includes USDC, USDT and USAT, with highest points for USAT over x402 or cNGN/Ripio wFIAT on Celo.

### Judges' Favorite — $500
Innovative Celo-native solution with real distribution. Mentioned primitives include fee abstraction and Self proof of personhood; use only when they strengthen FlowMint.

### AskBots Growth — $300 / $150 / $50
Baseline round: minimum 10 reviews; improve findings; second round before deadline; measured improvement above the round-two floor.

### cPay Feedback — $250
Closed-beta buyer-side testing with reproducible feedback.
